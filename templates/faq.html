Frequently Asked Questions

Q: How does the AI Quiz Generator work?

A: When a student or teacher requests a quiz, our system invokes the Google Gemini API (gemini-2.0-flash model) with structured parameters for category (SSC, Railway, Banking) and difficulty (Easy, Medium, Hard). It returns questions with option lists, correct answers, and detailed explanations which are instantly saved to our database.

Q: What is the fallback system if the Gemini API fails?

A: If the API key is not configured, or if network connectivity fails, our platform automatically draws random questions from a pre-defined local question bank compiled by educators for SSC, Railway, and Banking. This ensures mock tests always load without crashing the system.

Q: How is teacher feedback submitted?

A: A teacher logs in, selects a student from their student roster, reviews the student's attempt statistics, and fills out the feedback editor. Submitting feedback inserts a feedback record in our database and issues a real-time notification to the student's dashboard.

Q: How does the CAPTCHA protect the login route?

A: Our login system uses a Pillow-generated dynamic image CAPTCHA. The random characters are generated and stored in a secure Flask session. The login controller verifies that the client input matches the session CAPTCHA before checking passwords.
